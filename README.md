# Plugin Installation

This guide will walk you through the steps to install and configure the Lunu Plugin for your Shopware 6 online shop. This plugin allows you to add Lunu as a payment method.

1. Download the [plugin zip file](https://gitlab.lunu.io/widget/shopware-6/-/raw/master/LunuWidget.zip) from [our repository](https://gitlab.lunu.io/widget/shopware-6).
2. Log in to your shop as an administrator.
3. Navigate to Extensions > My Extensions.
   ![My Extensions section](/docs/images/myExtensions.png)
4. Click on the "Upload extension" button.
   ![Upload extension button](/docs/images/uploadClick.png)
5. Choose the downloaded zip file.
6. Click the toggle switch to activate the plugin.
   ![Activate plugin](/docs/images/activate.png)
7. Click the "..." button and choose "Configure".
   ![Plugin configuration](/docs/images/config.png)
8. Choose "Sales Channel" and enter your App ID and API Secret. Check "Sandbox mode" if you want to use it in test mode.
9. Click "Save".
   ![Plugin configuration](/docs/images/configurate.png)
10. Navigate to the "Sales Channel" page (for example "Storefront").
    ![Storefront page](/docs/images/storefront.png)
11. Scroll to the "Payment and Shipping" section.
12. Add "Lunu Widget" as a new payment method and click "Save".
    ![Add payment method](/docs/images/addPaymentMethod.png)
13. Enjoy!

You can find additional information and installation methods on the official [Shopware 6 documentation](https://docs.shopware.com/en/shopware-6-en/extensions/myextensions).
